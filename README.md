## Sobre o Projeto

O Citizen Assist AI é um protótipo de sistema desenvolvido em Python, com o objetivo de organizar e facilitar a consulta de informações sobre serviços úteis ao cidadão.

O recorte escolhido para o desenvolvimento do projeto é Serviços de Saúde.

O sistema tem como proposta organizar informações sobre serviços relacionados à saúde, permitindo cadastrar, consultar, pesquisar, atualizar, excluir e ordenar registros.

Dessa forma, busca facilitar o acesso e a organização de informações que podem ser úteis aos cidadãos.

### Descrição dos arquivos

- `main.py`: arquivo principal, responsável pela execução do sistema e interação com o usuário.
- `lista_encadeada.py`: contém a implementação das classes de nós e da lista encadeada.
- `servicos.py`: Define a classe Servico e os atributos de cada serviço.
- `README.md`: documentação e apresentação do projeto.

## Como executar o projeto

**1. Clone o repositório:**

```bash
git clone https://github.com/leticiaokano/Citizen-Assist-AI.git
```

**2. Entre na pasta do projeto:**

```bash
cd Citizen-Assist-AI
```

**3. Execute o programa:**

```bash
python main.py
```
